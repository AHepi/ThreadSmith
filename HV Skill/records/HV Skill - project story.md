# HV Skill - project story

*The HV Skill project's own record, kept here from 21 September 2026, in the same four files as the shared record (now in `Language/records/`, complete to log 59). The entries copied from the shared record keep their numbers. New entries here carry the letter H and one more than the highest number this log has used, H55 first; new decisions and lessons are numbered H1 onward. See READ ME FIRST in this folder.*

Authority: the skill, file 30, in `authority/hard-to-vary/` (SKILL.md and seven reference modules), with the uploadable archive beside it. The theory it draws its terms from is the Semantics project's authority document; the skill maps those terms to plain words in its own word list.

## The goal
A skill for asking, of any explanation, whether every part does work: whether changing a part would break its power to explain. Improve it from what each use teaches, and test it on documents nobody in the project wrote, read by a model that is not Claude, to find where its words break.

## How the pieces fit
The skill is the authority. Each test has a frozen plan in `tests/` (with its corpus and, where replies are marked, a marking plan frozen before any reply is read), a run kept as it came in `rigs/`, and a results file in `results/` that names what it did not test. Changes to the skill are proposed in results files and held until a test forces them; each change is a new numbered skill file.
