## What follows
- Predictions hold: file 32 frozen; the four kinds of H64 and the two faults of H62 closed by the counts; the README says so.
- A known fault recurs, or a new one appears in more than one run: file 32 is not frozen; the run that broke it is read and one further change waits for a further plan; the owner is told.
- Phase 2 fails a prediction: the failure is read for whether it is the skill's or the corpus's (plan 52's failure conditions), and the freeze waits.
