## The question
Does every passage of the skill do work that a recorded case or result holds in place, and do the five changes of draft file 32 each close the fault they were written for, on the evidence already in the record? What do the other projects hold about the skill that this project's folder does not?

## What runs
Opus 5 subagents through the session's Workflow tool, effort xhigh, every one first made to read the skill's tested authority (file 31, `authority/31/hard-to-vary/`) and to apply its procedure to the thing it judges, reporting with its marks. No agent may write anything anywhere; each is told to use only Read, Grep and Glob, and every agent's tool calls are audited afterwards; an agent that wrote or ran anything is reported and its return set aside.
1. **Look inside the other projects.** Seven scouts, each a slice of Semantics, Language and the tutorials (the shared record's entries 01 to 30 and its decisions and lessons; the Language project's own claims about the skill; the owner's-paragraph tests 21 and 22 and the scope contracts L63 and L64; the other model's audit packages; Semantics file 10 against the skill's word list, row by row; the audit workflow files 24, 27, 28, 30 and the Semantics record; the Semantics returns and the tutorials). Each returns findings with the file and the quote and what part of the skill it bears on. Every finding is then given to one refuter who reads the cited file and tries to show the finding wrong; findings the refuter cannot refute survive.
2. **Judge the five changes of file 32.** One judge per change, given the diff, the results that motivated it (54, H57, H59, H62, H64) and the surviving findings: the change as an explanation of why the fault will not recur, taken apart under the skill: remove the passage, swap it for a near neighbour, ask what holds it; mark it; a better wording if loose.
3. **Judge the whole skill, module by module.** Eight judges, one per file of file 32, each part marked held (by which recorded case or result), held if, loose, idle, borrowed, unknown, with the quote of what holds it. Every part marked loose or idle is then given to one refuter who searches the record for a case that holds it.
4. **Judge the planning skill's draft the same way**, one judge per file of Planning's file 1 except the loaned module, with refuters for loose and idle. (Planning's own work; its results go to that project.)

## What this does not test

- Reading a judge's mark as a test result. It is a reading of the evidence in hand, and says so.
