# W6 Addendum to plan W6 - the agents may research on the internet (decision W4)

Written 22 September 2026, after plan W6 was frozen and before its first agent started, on the owner's word: "Also give them access to internet for research if it's possible" (decision W4). Planning file 2's `freezing.md`: an addendum records a change before the first run and names what it gives up.

**What changes.** Plan W6 section 2 fixed the agents' tools as Read, Grep and Glob. The session carries two more tools the agents can load, web search and web fetch. All five agents (the three builders and the two judges) may load and use them for research. The rules they carry with the access:
- Anything read outside the repository is **claimed** (the skill's how-I-know tags: *seen* is what you watched happen; *claimed* is what a source says); it is quoted with its address and the date read, and it never stands as *seen*. A part of the model held only by a claimed source is *held if* the source is right, and says so.
- Nothing fetched is kept as a file (root conventions: third-party texts fetched are not kept; what rebuilds them is). The return carries the quotation and the address.
- No shell command and no write, as before. The tool audit gains a column: every web search and every fetched address, listed per agent.
- File 11 stays the authority, and a source's use of a word is not the theory's use of it.

**What it gives up.** The reading was confined to the repository and the theory, so that every holder could be checked in place by a judge; a holder on the web can be checked only by fetching it again, and it may have moved. Prediction W6.8 keeps its zero shell commands and zero writes; its audit adds the count and the list of web calls, with no prediction on them.

**What it does not change.** The five agents, their slices, the predictions W6.1 to W6.9, what counts as each outcome, and the read-only rule for every other project.
