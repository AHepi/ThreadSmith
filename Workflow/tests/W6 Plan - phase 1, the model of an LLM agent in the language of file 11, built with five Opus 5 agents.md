# W6 Plan - phase 1, the model of an LLM agent in the language of file 11, built with five Opus 5 agents

Frozen 22 September 2026, before anything runs, on the owner's word (decision W3: "11 is the new authority. Also, if the research is done and corpus compiled, time to describe LLMs within the language of 11. Use 5 Opus 5 agents with extra effort armed with current hard to vary to help."). This is phase 1 of W3, read with W5. It is not edited after the first agent starts.

## 1. The question
One claim, one aim. The claim: an agent built on a large language model can be described in the language of Semantics file 11 so that the description says which of the theory's objects the agent instantiates at one call, which across calls, which only with a record or a harness around it, and which never, and so that the description can be caught out by runs this repository can make (W3 section 1). The aim: the description, as this project's first authority file, with its own word list and its predictions frozen before it is judged. What would count as the claim failing: a model whose every part is a declared frame; a model with no prediction phase 4 could falsify; a model whose word list reads file 11 wider than written in a way its own judges find and the writer cannot repair without changing its terms.

**On "if the research is done and corpus compiled".** The research this phase needs is done: the record read (HV logs 49 to H69, Planning, Semantics to S76, Language to L74), the theory read in both versions, the plan frozen (W3) and re-based (W5). No corpus is needed for this phase: the model is a reading of the theory and of the evidence in hand. The corpus that phase 4 needs (documents no run has read, fetched by manifest) is not compiled and is that phase's first output; the evidence in hand and the reserve are listed in W3 section 2 and W5.

## 2. What is fixed
- **The authority:** Semantics file 11 (decision W3), read beside file 10; every quotation carries its Part and a file mark ("10 and 11", "10 and 11 (reworded)", "11 only") for traceability, as W5 section 1 says. File 20 stays set aside.
- **The plan:** W3 read with W5. The sketch M1 to M10 as W5 leaves it, the declared indices, the operations of Part XIV's dependence order (W3 section 6), the definitions of section 7, the predictions P1.1 to P1.4 (with P1.1 in W5's form) and P4.1 to P4.7.
- **The skill the agents carry:** HV file 33, frozen, all eight files, with `references/building.md` opened by the builders and the full procedure run by the judges. W5 section 5's cost is carried: the skill's word list maps *fitted* to file 10's unqualified Derivation 3; every agent is told file 11's qualification in file 11's words before it starts.
- **The agents:** five Opus 5 subagents at effort xhigh, the cap of five for the round (owner's words after H7). Three builders and two judges. Never Fable 5.1 (H4, H7). Read only: Read, Grep and Glob; no shell command; no write; nothing in any other project touched (H8, S6). Every agent's tool calls audited afterwards from the transcripts.
- **The evidence in hand** the builders may cite, all read only: W3 section 2's list; the rigs and transports (`HV Skill/rigs/`, addendum H61, plan 52); the Semantics project's fresh-agent instruction packs from S65 (decision S5: "Each new step will be performed by a separate agent") and its two-stage rounds (S7), which are stateless arrangements in the record; the Language project's outside agents (L70). None of it is a test of the model (W3 section 3).
- **What the model does not claim** (W3 section 4, last paragraph): class membership; creativity; knowledge; Deploy attributed to any agent.

## 3. What runs, in what order
1. **Three builders, in parallel**, each handed the whole of file 11, W3 and W5, the skill, and one slice of the sketch, told to build that slice the way `building.md` says: jobs first (the owner's unknowns that fall to the slice, quoted; jobs the builder adds, tagged), then parts, each on a quoted sentence of file 11 with its Part and file mark, each with what would count against it, each tested by remove, swap, poke, the best rival and what tells them apart, and marked with one of the eight marks and a provenance; then the word-list rows for every term the slice uses; then self-falsification. The slices: **A, the call** (M1 to M4: an execution, the context and emission, the declared organization at the grain of text, the weights' organization and its selected transport under the qualified Derivation 3, what a run settles, a skill file as a carrier and representation as a fidelity fact). **B, the arrangement** (M5 to M8b: retention, ownership, boundary and continuity, stateful and stateless, what the context must carry, external memory and the carrier, the two losses under a harness). **C, the practice and the map** (M9 and M10: a scrutinizable policy, the modules-opened trace, the record as history and receipts, the declared inputs; and the model's central table: every operation of Part XIV's dependence order placed in one of four columns, at one call, across calls, only with a record or a harness, never, with a quoted holder for each placement). A builder that finds its slice's parts touch another slice's says where and how.
2. **Assembly, by Claude.** The three returns are kept unchanged in `rigs/W6 builders/`. The model is assembled as one file, "W7 Model - an LLM agent in the language of the semantics (draft)", in `authority/`: the parts in the builders' words where they stand, the seams between slices resolved and said, the word list merged with one row per term, the operations table, the predictions (W3's P4.1 to P4.7 as W5 leaves them, and any prediction a builder adds, marked as added by which builder), and what the model does not claim. Nothing a builder marked loose, idle or unknown is promoted; the assembly records every place the builders disagreed.
3. **Two judges, in parallel, on W7.** The file-11 judge: every row of the word list and every quotation, at the Part named, read no wider than written; every construction marked; the two-file marks right; the eleven unmapped notions (H69) each given a row or declined with a reason. The procedure judge: the model as an explanation under the skill's full procedure: the question frozen, the jobs tagged (the owner's six unknowns given; the builders' and the writer's additions named), every part marked with its holder quoted and its provenance, the whole-explanation checks by their Step 5 names, whether each prediction is a count that could fail, the best rival model and what tells the two apart, the operations table checked cell by cell against the holders it quotes.
4. **The frozen model, by Claude.** Every edit the judges' evidence forces goes into "W8 Model - ... (frozen)"; candidates are held in the results file. The results file "W6 Results" ticks the predictions below, names what was not tested, and gives the tool audit.

## 4. What counts as each outcome, decided before reading
As W3 section 7, with W5 section 1's two-file wording. Added for this phase: **a builder's part is kept** when it carries a quoted sentence of file 11 at the Part named, one of the eight marks, a provenance, and what would count against it; a part missing any of the four is returned to the builder's "could not settle" list and is not in W7. **The slices touch** where two builders state a part with the same object (the same port, the same predicate of file 11) or where one builder's holder is another's part. **An operation is placed** when its column carries a quoted holder from file 11 or the record; a placement with no holder is "unknown", and unknown is a placement the table shows.

## 5. Predictions, as counts that could fail
- **W6.1 (P1.1).** Every row of the model's word list quotes file 11 with its Part and a file mark, or is marked as a construction with the passages it is built from. The judges report zero rows that contradict file 11 and zero unmarked constructions. Any one reported falsifies it, and the row is reworded before W8; if the contradictions run through the model's terms, the model is rebuilt from the theory.
- **W6.2 (P1.2).** Q1, Q2 and Q6 each receive a statement whose falsifier is a run this repository can make; Q3, Q4 and Q5 each a statement or a named reason the theory as written cannot reach them. Already recorded as not reached: the attention half of Q1 and the generation half of Q5. Any unknown without either is reported by name and falsifies this.
- **W6.3 (P1.3).** Every one of the eleven unmapped notions of H69 is given a row or declined with a reason; the fourth (the finite monotone theorem's condition) and the eighth (fallibility without falsehood-as-work) are rows. One missing falsifies it.
- **W6.4 (P1.4).** The procedure judge quotes a holder for every part; any part left loose or idle after its search is held or cut before W8, part by part, with the holder or the cut named. No count of loose parts is a verdict.
- **W6.5.** The three builders, working apart, disagree on the statement or the mark of at least one part where their slices touch (the seams named in section 3: M4 with M5 on what a carrier at a call is; M8 with M9 on the boundary; M10 with the table on the record). Zero recorded disagreements falsifies it, and then the slices were cut so as not to touch; the seam is marked unknown in W7 and the judges are told.
- **W6.6.** At least one part of the sketch M1 to M10 is cut, merged, split or restated in substance by a builder's self-falsification, with the quotation that forced it. Zero falsifies it: the builders transcribed the sketch, and W7 says so.
- **W6.7.** The operations table places every operation of Part XIV's dependence order (twenty rows, as W3 section 6 lists them) in one of the four columns with a quoted holder, with at most two placed "unknown". Three or more unknown falsifies it.
- **W6.8.** The tool audit shows zero shell commands and zero writes across the five agents. The last two rounds showed three of five and zero of two; one shell command falsifies this, and the agent's return is read with and without whatever the command reached.
- **W6.9.** The file-11 judge and the procedure judge give the same mark to every part they both mark, or the disagreement is listed; at most three parts disagree. Four or more, and the marks on those parts are unknown until a third reading runs (Planning file 2), which no plan here runs; W8 says so on each.

## 6. What follows either way
- All hold: W8 is frozen as this project's first authority; phase 2's plan (the reading, with its coverage map) is written next, on the owner's word.
- W6.1 or W6.4 fail: reworded or held or cut before freezing, part by part; a second judging round only if the model is rebuilt, and then five judges at most, on the owner's word.
- W6.2 fails: the unknowns not reached are written in RELATIONS as an ask for the owner; the model freezes with them named.
- W6.5 or W6.6 fail: W7 says the sketch was transcribed or the seams untouched; the judges are told to press there; if they too find nothing, the seams are marked unknown in W8.
- W6.7 fails: the unplaced operations are listed in W8 as unknown with the test that would place them, and phase 5's plan starts from that list.
- W6.8 fails: the return is read with and without the command's reach; nothing else changes.
- W6.9 fails: the disputed parts are marked unknown in W8, each with both judges' words.

## 7. What would count as failure of the test itself
- A builder returning parts without holders throughout: the slice is not built, and the phase reports it rather than filling it by the writer's hand.
- The two judges agreeing on every part while the builders disagreed on several: the judges read with the writer, not against; W8 says so and the next round changes the judges' framing.
- The judges finding the writer's assembly, not the builders' parts, to be where the faults lie: then the assembly is redone from the returns and judged again.

## 8. Known weaknesses, stated before use
- Every agent is of the kind the model describes, and armed with the same skill (W3 section 10).
- The skill the agents carry maps *fitted* to file 10's unqualified Derivation 3 (W5 section 5); each agent is told the qualification before it starts, and a mark that rests on the unqualified form is struck at assembly.
- Three builders on three slices can make three models that do not join; the assembly is the writer's and is the likeliest place for a seam to be papered over. W6.5 and the judges' brief are the guard.
- No reader under test runs in this phase; every claim about what an agent does is a reading of the record's runs and of the theory.

## 9. What this plan does not test
Anything against a reader under test; the model's predictions (phase 4); the skill's faults; the theory; file 11's standing (the Semantics project's round S76).

## 10. Traps
- Reading the builders' returns as the model. The model is W8; the returns are raw evidence, kept as they came.
- Promoting a part a builder marked loose because the assembly needs it.
- Counting holders as a score. One part with no holder is one part unheld.
- Letting the file-11 judge's zero read as held. A reported zero is a fact about the search (W3 P1.1).
