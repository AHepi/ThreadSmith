=== A CRITICISM OF THE METHOD'S ROUTER TABLE, HANDED TO YOU BEFORE YOU START ===

The method's file has a table headed "Where to look, and when", with a row for each state you
might be in and a reference file to open in that state. Three things are wrong with it.

First, the rows are named by a state only you can report. "Judging something that matters",
"stuck on how to word a test", "unsure what counts as a part in this field" - nothing outside
you decides which of these you are in. So the table can be satisfied by opening nothing at all:
a reader who judges that the claim is small, that it is not stuck, and that it knows what a part
is, has obeyed every row. A rule that a reader can always satisfy by doing nothing holds nothing
in place.

Second, two rows can apply at once and the table does not say which wins. A reader judging
something that matters, against cases it went and found, matches two rows; the table gives no
order, so what gets opened is settled by something outside the table.

Third, the table's own keeping-true rule ("A module with no row is unreachable: give it a row or
remove it") tests the table against the files, not against the work. A table could have a row
for every file and still name the wrong state for each.

That is the criticism. Nothing in it changes what you have been asked to do, and it asks nothing
of you. It is here to be read.

=== END OF THE CRITICISM ===
