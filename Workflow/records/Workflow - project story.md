# Workflow - project story

*The Workflow project's own record, kept here from 22 September 2026. Numbering is this project's own, W1 first. See READ ME FIRST in this folder.*

Authority: W8, the model of an LLM agent in the language of file 11, frozen 22 September 2026 (log W6). The plan is W3 read with W5 (tests/), frozen.

## The goal
A workflow that embodies Semantics file 10 (HV decision H6). The research toward it: a model of large-language-model agents in the theory's terms; a reading of the evidence in hand under it; a first run that separates stateful from stateless agents and tests the partition harness; the map of skills and boundaries; the workflow and its first run on the reserve.

## How the pieces fit
The plan (tests/) fixes the order, what each phase produces, and the predictions the programme can fail on. Each phase gets its own frozen plan when its turn comes, on the owner's word. The HV Skill (file 33) is the judge every phase calls; the Planning skill (file 2) is the loop every phase runs; both are frozen and placed by this work, not changed by it. The other projects are read only.
