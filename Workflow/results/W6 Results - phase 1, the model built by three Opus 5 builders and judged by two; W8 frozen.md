## Lessons
- **W4.** The assembly program that made draft W7 truncated table cells (leaving unpaired quotation marks), copied one builder's (K) note into the rule-application row as if that builder had placed it, and left the word list unmerged while its preamble said it was merged; and no program checked the file marks against file 10. Fixed: `assemble_w8.py` carries the cells whole, keys the rows by their tags in an order that cannot cross, merges rows by the judge's rule (one sentence, one term), sets every file mark by program from the pair of files, and prints a log of every edit; the program and its log are kept beside the returns.
