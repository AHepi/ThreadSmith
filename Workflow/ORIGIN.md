# Origin

**The owner's words.** HV decision H6, recorded 21 September 2026 in the HV Skill's Decisions file and quoted here whole, because this project exists to carry it out:

"The end goal is an entire workflow that embodies the yet incomplete semantics theory HV is based on. I learned that creating a determinist harness that serves as an attention and token distribution system is difficult to implement without destroying the already latent LLM capabilities. The capabilities seem to be centred around statefull vs stateless agents. It turns out built in context should consume part of the reasoning architecture specified in the semantics. As for exactly what is to be determined. Externalising parts of memory are still important, and relevant to managing attention. As to how, I'm unsure. Whether LLMs guide attention in planning, exploration and execution is yet unknown. Maybe it needs to handle bits of attention and bits generation. But which, I'm not sure. To understand which, designing a model of LLMs within the language of the semantics needs to be resolved. Which skills to have, and where the boundaries lie is the first step. Right now we have planning and HV. Nothing else can move forward without a sense of how LLMs fit into the larger semantics picture. First goal is the research. Harden HV and planning right now, freeze them, then move to a structure research plan based on semantics 10."

Earlier, on the HV Skill (decision H2, 21 September 2026): "I actually intend on eventually making your project a general purpose reasoning engine. So you're nowhere near finished."

And the word that opened this project (decision W1, 22 September 2026), after the report that HV file 33 and Planning file 2 were frozen and the research plan was next: "Yup continue. Do it".

**Where the programme's content came from.** Three places, all older than this project and none edited by it: Semantics file 10, the theory, whose Part XIV dependence order gives the operations a workflow would have to carry and whose Parts I, II, IV, IX, XII and XIII give the terms for a call, a carrier, a selected transport, a history, retention and a scrutinizable policy; the HV Skill's record, whose runs (logs 49 to 54, H56 to H64) are the only evidence in hand about readers under test, and whose hardening (H68, H69) left the word-list mismatches and the unmapped notions that a model of agents has to place; and the Planning skill (file 2), whose loop every phase of the plan follows.

**What it is for.** To find out how an agent built on a language model fits into the theory's picture, so that the skills the workflow needs, and the boundaries between them, can be drawn from that rather than by habit; then to build the workflow and test it on the reserve. The two skills that exist (HV, Planning) are frozen and are placed by the map, not changed by it.
