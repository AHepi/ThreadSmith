# Semantics - project story

*The Semantics project's own record, kept here from 21 September 2026 (decision S1), in the same four files as the shared record (now kept in `Language/records/`). The entries copied from the shared record keep their numbers, so every reference in the repository still holds. New entries here carry the letter S and the next number in the shared sequence at the time of writing, S60 first, so they read against the shared sequence and cannot collide with it. See READ ME FIRST in this folder.*

Authority document: "Claude Fable Semantics - standalone theory", [authority/10 Claude Fable Semantics - standalone theory.md](<../authority/10 Claude Fable Semantics - standalone theory.md>), frozen. A later version exists, "20 Claude Fable Semantics - revised standalone theory.md", held by the other model and not given to Claude (log 26); it is not in the repository.

## The goal
Audit the authority document from outside: find described situations where the theory's verdict and a thoughtful person's verdict come apart, by handing a second language model a bounded, positively worded workflow (file 24) and reading what it brings back against the theory. The theory is the fixed point the other two projects quote; this project is the one that tries to break it.

## How the pieces fit
The other model holds the workflow (24) and the revised theory (20). Each round is one instruction file in `tests/` (27, 28, 30, 41, 55, 57), pasted to it; what it returns is kept as it came in `results/` (55, 57; earlier returns are quoted in the log only) and read in the log entry of the same number. The gauge of the audit is the list of judgement phrases still standing: phrases in the theory or its amendments that a thoughtful person has to supply the meaning of. Words from the authority document and their plain-word mapping are in the shared project story, "Words from the authority document", and in the skill's word list.
