# Semantics - the record of this thread

From 21 September 2026 the Semantics project keeps its own record here, in the same four files as the shared record at the repository root: project story (the log), Decisions (the owner's words), Lessons (only failures), Status (the summary). The owner asked for it so that each project's files stay inside its own folder, with only the read-me and navigation files outside (decision S1). The Language project did the same the same day, in `Language/records/`, and this folder follows its conventions.

## How the two records relate
- **Before this folder existed**, every Semantics entry was in the shared record at the root. The twelve Semantics log entries there (24 to 31, 41, 55, 56, 57), the seven owner decisions on the audit (7, 20, 21, 23, 30, 44, 45) and the five audit lessons (26, 27, 35, 49, 50) are copied here verbatim, numbers unchanged, so this folder reads on its own. The copies are marked.
- **From here on**, a Semantics entry is written in this folder only. A new log entry carries the letter S and the next number in the shared sequence at the time of writing (S60 first); a file made under it is named "S60 ...". New decisions and lessons are numbered S1 onward. The letter says the thread; the number says roughly when.
- **The shared record at the root** is complete to log 59 and is not updated from here after 21 September. The navigation files at the root (README, START-HERE, LEGEND, RESEARCH-CONVENTIONS, the records read-me) say where each project's record now lives.

## Read in this order
1. This file.
2. **Semantics - project story.md**: the log, with the goal, how the pieces fit, and the next step.
3. **Semantics - Status.md**: the short summary.
4. The live instruction in `tests/` and the latest return in `results/`.

## Traps
- Editing a copied entry. The copies are the shared record's text; a correction is a new entry.
- Numbering a new file by the shared record's last number alone. Use this log's S-number.
- Reading the shared Status at the root for this project after 21 September. It is not updated from here.
