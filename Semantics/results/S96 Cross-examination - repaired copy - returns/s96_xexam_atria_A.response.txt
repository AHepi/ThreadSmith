**1. Q5 · L329–L331 — a symbol defined two ways, a number lost, and unknowns never introduced.**

Three faults in one passage. (a) "For linear \(A\) and feature \(c^\top\), identification is \(\ker A\subseteq\ker c^\top\)" uses \(A\) for the measurement matrix, but \(A\) is the set of admitted edits from L91 onward ("\(A\) is a set of admitted edits"), and Part VII itself uses \(A\) in that sense at L325 ("Under \(A\) containing interventions on \(H\) and \(\theta\)"). (b) The claims run (I1), (I2), (I4): (I3) is missing — a dropped claim or a numbering slip. (c) The variables \(x,b_A,b_B\) are never introduced; the reader must infer the column order to check "the readings identify \(b_B-b_A\) and not \(x\)" (which holds only for the order \((x,b_A,b_B)\)).

```
Let \(Z\) be the admitted states, \(g:Z\to Y\) the measurement, \(f:Z\to F\) the feature. The fibre at \(y\) is \(Z_y=g^{-1}(y)\). The feature is identified at \(y\) exactly when \(Z_y\neq\varnothing\land|f[Z_y]|=1\). (I1) It is identified on every attainable \(y\) exactly when \(f=\bar f\circ g\) for some \(\bar f\). (I2) For linear \(g\) and linear feature \(c^\top\), identification is \(\ker g\subseteq\ker c^\top\). (I3) Repeating rows changes no kernel; an independent calibration can.

For the two balances \(\begin{pmatrix}1&1&0\\1&0&1\end{pmatrix}\) reading an unknown mass \(x\) with biases \(b_A,b_B\), the kernel is spanned by \((1,-1,-1)\); the readings identify \(b_B-b_A\) and not \(x\). This is an account of a limitation. "Set \(b_B=0\) because it gives the mass I favour" is not an inference from the readings; it is circular, though the value it sets might be the target's.
```

If a claim was dropped at (I3), restore it and keep the numbering; the renumbering must also be checked against Part XVI, which is not among the lines examined.

