Theorem: "If Γ is finite, S is upward closed, and Γ ∈ S, then the critical singletons are exactly ∩min S and the globally indispensable ones are exactly ∪min S."
Proof: "A member of a minimal support is critical for it. If d is critical for W, finiteness gives a minimal U ⊆ W; if d ∉ U, upward closure makes W \ {d} a support. Deletion of d from Γ preserves support exactly when a minimal support omits d. ∎"

Let's trace the proof for "critical singletons are exactly ∩min S":
- Suppose {d} is critical. Then Γ ∈ S and Γ \ {d} ∉ S. Let U ∈ min S. If d ∉ U, then U ⊆ Γ \ {d}, so by upward closure Γ \ {d} ∈ S, contradiction. Thus d ∈ U for all U ∈ min S, so d ∈ ∩min S.
- Suppose d ∈ ∩min S. Then d ∈ U for all U ∈ min S. If Γ \ {d} ∈ S, then it contains a minimal V ⊆ Γ \ {d}, so d ∉ V, contradiction. Thus Γ \ {d} ∉ S, so {d} is critical.

So the set of elements whose deletion destroys support is ∩min S.
