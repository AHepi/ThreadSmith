**The fix is maths and code, not prose.** For each challenged item, the checker:
1. says in one line whether the challenge holds. It holds against the maths, against the words, against an invention only, or it does not hold.
2. where it holds, writes the fix as maths: the changed or new definition or claim, in the formal core's notation, beside the old one.
3. puts the fix into a copy of the model program and runs the claims it touches.
4. changes the prose text only by:
   - deleting a span;
   - replacing a span by its formal statement;
   - replacing a span by a pointer to the definition or claim.

   It never adds explanatory prose. Everything else in the text stays as it is.
