## In brief

Every chosen case except one reads the same on the scrubbed text as on draft 5. Where draft 5 reached the fixed verdict, the scrubbed text reaches it from the same lines. Where draft 5 was silent (O1's "retreat", O27's "mostly"), the scrubbed text is silent in the same place. No case moves away and none moves toward.

This is why. Each chosen case gets its verdict from (E), (A), the conflict relation, Derivation 3's population, the dependence order or Part IX's active routes. None of these used a forbidden word for its content, so the scrub only renamed them. The forbidden words sat in two places:

- **The assessor level:** established, fits, receipts, refutes.
- **Names:** knowledge, proof, derivation, primitive, support.

The assessor-level cases are O1, O24, O27 and N5. They read the same through "ruled out" and "not ruled out", because in each of them the verdict turns on whether a record decides between two candidates, never on whether anything counts *for* either.

**The one case that changes is N10 (O61, the burned notebook). It is NOW SILENT.** Its questions ask whether Halima created *knowledge*. The word no longer occurs anywhere in the scrubbed text. (EK) became (EX), "Created explanation", and the text marks that name as provisional and leaves it to the owner (l. 443). The formal conditions are the same, so if the owner rules that the case's "knowledge" is (EX), the first question reads the same. The second question would then pull away from the verdict, because the new name points at the explanation rather than at who holds it.

**Five places where a reading could now move, none of which moves a verdict here:**

- **l. 397:** arguments may have "stated assumptions" as leaves, so an assessor can rule a rival out by assuming it fails. Watched on O24 and N5.
- **l. 441:** ProducedBy now "attributes the repair to each contribution the history contains", which is wider than l. 307. Watched on O52.
- **l. 522:** the refusal now covers any "function that orders explanations", wider than draft 5's "merit function". Watched on N7's "fuller".
- **l. 526:** "defined only by its own construction" no longer echoes O37's "justifies".
- **l. 397:** "A record … does not rule out" is true of every record once only arguments rule out. Watched on O16.
