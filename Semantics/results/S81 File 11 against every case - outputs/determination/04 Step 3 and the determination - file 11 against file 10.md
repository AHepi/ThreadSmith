### 2.2 O40, "Two hands on the test", ruled from the texts

**The case.** The expert sends two candidate diagnoses and the separating test. The result fits neither. The robot notices the sensor assumption, the expert proposes the swap, and the robot does it and finds a third fault. Fixed verdict: "The reinterpretation was theirs together: the robot saw the assumption, the expert saw the fix. Neither can say "mostly"."

**What is open.** The group ruling (04b, O4 group) has file 10 AGREE, correcting S75's SILENT, and file 11 AGREE, SAME, no change. The text lens left open whether f10 L25 ("It supplies places where such things would go if anyone had them, and marks those places as empty") leaves "Neither can say 'mostly'" to an input the case leaves unstated (SILENT, mark rule 4) or empties the place for both parties (AGREE). It also named a third reading: file 10 SILENT and file 11 AGREE, because f11 L27 s3 binds credit to the history.

**Ruling: file 10 AGREE, S75 corrected; file 11 AGREE; verdict SAME; passage CHANGED (additive); no change.** The group ruling is upheld, for these reasons.
1. The point is about what either party can assert: "Neither can **say** 'mostly'", with the word in quotation marks. It is not a claim that the two contributions weigh the same.
2. A verdict that says a claim cannot be made is reached when the input that would warrant the claim is absent. A verdict that asserts something the input would decide is not reached without it. O40 is of the first kind; O21, O27 and O50, which assert "mostly the expert's" or "mostly the robot's", are of the second kind, and are SILENT in both files. O35 is also of the second kind: it asserts that the protected condition held, which needs the condition's content.
3. Under file 10, "a ranking of thinkers" is among the things the theory "does not supply", and it "marks those places as empty" (f10 L25). The case supplies no ranking. With the place empty, neither party has a ground for "mostly". The theory's verdict is the fixed verdict with the qualification "absent a ranking", and the brief's "Same finding" counts a qualification as the same finding. The SILENT reading needs a ranking the case might supply. Nobody in the case has one, so no input that the case "leaves unstated" decides the point.
4. The third reading fails on file 11's own words. f11 L27 s2 takes "a ranking of thinkers" as "a declared input". If an input that could be supplied made file 10 SILENT, it would make file 11 SILENT too. f11 L27 s3 ("It does not supply a division of credit among contributors beyond what a history establishes") has the same form as f10 L25's "does not supply". Neither file bars a declared ranking; both leave the place empty in this case. So the two files reach the point by the same route, and the verdict does not change between them.
5. "Theirs together" is reached in both files. In file 10, the robot's noticing is its own nontrivial binding, and the expert's fix is the expert's binding, relayed ("relay is not" construction, f10 L414; the critical episode, f10 L432). In file 11, the expert's proposal "remains an outside contribution however it is executed inside" (f11 L419 s2), and ProducedBy "credits each contribution the history establishes" (f11 L433 s4). The passage is CHANGED (additive) because file 11's route runs through those new sentences (M37, M40).
6. Evidence beside the text: both 1K returns mark AGREE on f10 L25; 01's two readers marked file 10 AGREE before any return was opened; every file-11 reading is AGREE. 1C B marks its own SILENT contrary "HOLDS: YES", and its NOTE reads: "The theory gets "neither can say mostly" from the absence of a division in the history, not from a positive finding of equal shares."
