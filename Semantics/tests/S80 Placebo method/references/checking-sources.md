# Checking sources

Open this before you check quotations, citations, figures or facts in a document against the sources they come from.

The idea that runs through all of it: **a citation is a claim about another document, and only that document can confirm it.** Plausibility, memory and the reputation of the source are not checks.

Contents: 1 Before checking. 2 While checking. 3 Figures and data. 4 Afterwards. 5 Traps.

## 1. Before checking

**Example.** A reviewer is sure a well-known quotation is accurate, having seen it many times. On opening the original speech, they find the familiar version is a later paraphrase, and the speaker's actual words are longer and less quotable. Everyone who had "seen it many times" had seen the paraphrase.

- **List what is to be checked.** From your inventory, list every quotation, every citation, and every figure that comes from outside the document, with where it appears and what it is used for.
- **Decide what you can open.** Some sources you can open; some are behind paywalls, out of print, or unpublished. Mark each as available or not before you begin, so the unavailable ones are reported rather than forgotten.
- **Decide how far to go.** For a short review, check the citations the main claims rest on and a sample of the rest. For a full review, check all you can. Say which you did.
- **Prefer the original.** A source quoted in another source is second-hand. Check the original where you can; if you cannot, say the check was against a secondary source.

## 2. While checking

- **Quotations:** compare word for word. Check spelling, punctuation, capitalisation, omissions (which should be marked with an ellipsis), insertions (which should be in square brackets) and emphasis (which should be marked as added if it was). Then read the surrounding sentences in the source and check the quotation does not change the sense by what it leaves out.
- **Citations for claims:** find the passage in the source that supports the claim. If the source supports a weaker or narrower claim, say so and suggest wording that matches. If the source does not contain it at all, report that.
- **Reference details:** authors (spelling and order), year, title, journal or publisher, volume, issue, pages, edition, and any identifier. Check the in-text citation matches the reference list entry.
- **Record the result for each item:** *confirmed* (you found it in the source), *partly confirmed* (the source supports something close but not the same; say what), *not found* (you looked in the source and it is not there; say where you looked), or *not checked* (you could not open the source).
- **"Not found" is about your search.** Say what you searched: the whole source, the chapter cited, the page cited. The author may know where it is.

## 3. Figures and data

- **Check the figure, the unit, the date and the definition.** "Unemployment was 5%" can be right for one month, one country and one definition, and wrong for others.
- **Check any transformation.** If the document converts, rounds, averages or combines figures from a source, redo it.
- **Check comparisons use comparable figures:** same period, same place, same definition, same units.
- **Check the latest figure,** if the document presents a figure as current. Say which version you checked and when.

## 4. Afterwards

- **Report every item that is not confirmed,** with its location and its status.
- **Report the ones you could not check** as a list, so the author can check them.
- **Keep the three apart:** what the source says, what the document says, and what you recommend.
- **Say how many you checked out of how many there are,** and how you chose them if you sampled.

## 5. Traps

- Marking a citation as confirmed because the source is reputable.
- Checking a quotation against memory or against another document that quotes it.
- Stopping at the title of a source without finding the passage.
- Reporting "not found" without saying where you looked.
- Letting unavailable sources drop out of the report instead of listing them as unchecked.
- Checking the figure but not its date, unit or definition.
