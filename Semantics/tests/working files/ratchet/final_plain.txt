Answers

(1) PARTLY. Once a correction takes on the failed summer as a job, the set of versions that fit always shrinks, and the old explanation is the version that drops out. This held in every check: about 274,000 cases across 20 gardener families, plus the myth and the tilt. But the mistake can come back elsewhere. Some versions fit every recorded summer and the failed one, yet repeat the old error in another early-variety summer: 18 of 52, 71 of 208, or 56 of 64. Only a job covering every season the world allows shuts them all out. On that question the old explanation was never right; the failure only showed it. And a narrowing can drop the job at any time.

(2) NO. The theory has no measure that defines a good explanation; the set of versions that fit "grades nothing". In one shared family, the good rescue, the wet-spring rescue and the one-summer exception all fit the record. Only the seed trial or the open question separates them, and that is a plain check against the world. On the same jobs, adding a part never makes an explanation harder to vary, and that includes the good rescue. Where the record cannot tell rain from the variety, the two rescues come out exactly equal. "More versions fit" is provable only for a narrowing (52 against 13). But an honest limit that was never widened shows the same, so only the record shows a retreat.

(3) PARTLY. The limit cannot be relaxed. File 00's reasons apply to one's own correction as fully as to anyone's. But it can be met. Require the later explanation's family of variations to contain the earlier explanation as a member, with the added part switched off or the changed part restored. Then there is one explanation, one interpretation and one family, and the strict shrink follows.

Proposal

Add a lemma (a truth the theory proves) to draft 3, Part VI, after the hard-to-vary lemma, and make a one-clause edit to that lemma. It states:
- the strict shrink, with the earlier explanation as the excluded version;
- a companion: an addition that rescues must be essential at the failed job, so an idle add-on never rescues;
- the same result for a narrowing, whether or not the dropped job was ever claimed (only the historical index says which);
- four limits: the mistake can return where no job reaches it; on the same jobs an extension is never the harder to vary; two rescues that both fit are not told apart; without the earlier member, the shrink need not be strict.

Every hypothesis was checked: drop one and a non-strict case appears.

It ranks no one. It compares two subsets of one family, never two explanations. Its hypothesis is about content, not authorship, so a rival's extension gets the same result. Where neither explanation is an edit of the other (the tilt and the myth), it says nothing. It asserts that an excluded version exists and counts nothing, so no choice of variations flips it.

Why a lemma

It follows from the existing definitions for every family, so it cannot flip a case. As a measure it would need a merit function, and its counts flip with how the variations are listed (1 to 96 in one listing, 64 to 1 in another). As a condition of the basic test it would refuse the good rescue, and it still could not separate good rescues from bad.

Uncertain

- What a "job" is. The texts do not define it; I take it to be a question.
- Whether an edit can undo a correction that re-reads a kept part.
- Whether the owner wanted a mark, which needs the record.
- The models are toy models.

Bottom line: a record of rescues is not redundant. The lemma proves the true part of the owner's view and states where it stops.
