Original conceptual proposal, not book evidence. No machine has been implemented and no experiments have been run. The attached books were not read for this independent proposal.

One concrete candidate is a bounded program construction machine. It would begin in a deliberately small environment containing one filled figure and a movable light sensor. Each observation supplies light intensity, sensor position, elapsed time, and the preceding movement. The experiment supplies sensor calibration and movement coordinates. It supplies neither shape names inside the processing machinery nor operations for detecting corners or curvature. This restriction makes the source of any later geometric distinction easier to inspect.

Its elementary operations would read a stored value, write a stored value, copy a value, compare values, add, subtract, multiply, branch on a comparison, and repeat a bounded sequence over stored records. Programs could create records whose fields contain values or references to other records. Every repetition would have an execution limit. These operations provide arithmetic and addressable memory, but they do not contain completed definitions of circles or squares.

Every observation would append an event to an event record. The machine could immediately connect repeated observations at the same position and observations linked by its own movements. Initially, these connections would express supplied spatial and temporal relationships rather than learned object knowledge. Additional structure would arise when constructed programs compared events and wrote new records: for example, a program might record positions where neighboring intensity readings differ. Such a relation would be a product of an executed program, with links back to the observations that produced it.

The program constructor would build candidate programs deterministically from the elementary operations. It would enumerate short well-formed expressions first, respecting whether each expression produces a value, a record, or a condition. It would then compose those expressions into bounded programs. Its available constants would include a small fixed set of arithmetic constants and values encountered in observations. A candidate could predict an unobserved sensor reading or, during a separately identified teaching phase, associate an observation history with a supplied category word. Category words would be outputs to explain, never inputs available to the candidate during recognition.

This construction process would contain general operations for composing programs, but no catalogue of circle explanations or square explanations. It might construct arithmetic relationships among sampled positions or repeated relationships among intensity transitions. Whether those relationships emerge within the available resources is an experimental question. I cannot defensibly promise that elementary enumeration will discover useful geometry efficiently.

A prediction ledger would retain each tested candidate, its predictions, and the observations that agreed or conflicted with them. In the initial noiseless environment, a candidate that predicts an incorrect sensor reading would cease to be an adequate account of that recorded situation. Agreement would only mean that the candidate remains compatible with the observations. Several incompatible candidates could remain active simultaneously.

Revision would also be executable. The program constructor would replace subexpressions of a failed candidate with other well-formed expressions, considering the smallest replacements first. Every replacement would be checked against the retained observations, not merely the most recent failure. If local replacements failed, construction would resume from the elementary operations. The location of a failed prediction would guide the search without being treated as proof that a particular instruction caused the conceptual mistake.

Reusable operations could emerge without random mutation. When an executed subprogram contributed to a surviving candidate, the constructor could register its exact instruction sequence as a callable operation. Repeated sequences differing only in input values could become parameterised subprograms when substituting explicit arguments reproduced their previous executions. Their complete definitions would remain inspectable. This supplies a limited mechanism for building larger programs from earlier constructions; it does not establish that the resulting vocabulary will support general thought.

Temporal memory would enter directly because candidate programs would operate over the event record and persistent working records. A candidate could compare an earlier observation with a later one, retain a running relation, or use an earlier event to determine what the current observation means. Constructed summaries could accelerate those operations, but their outputs would be checked against replay of the retained events. A memory-dependent task would deliberately give different histories the same final observation. Resetting the relevant working record should then remove the machine’s ability to distinguish them.

For active observation, the machine would ask its surviving candidate programs to predict readings at reachable, unvisited sensor positions. It would prefer a position where those predictions disagree, using travel distance and a fixed ordering to resolve ties. After moving, it would add the actual reading to the event record and reconsider the candidates. If all candidates agreed, it would continue inspecting unvisited positions while resources remained. Agreement among current candidates would not establish that the candidate set was complete.

Search would have explicit limits fixed before each run: maximum program length, candidate evaluations, primitive instruction executions, sensor movements, and retained events. Exhausting a limit would produce an unresolved result with the remaining candidates and the limiting resource recorded. There would be no hidden unlimited search. Successful runs would be reported together with their actual costs.

The first aim would therefore be modest: discover an executable distinction that survives new positions, sizes, observation orders, and withheld examples, while exposing how earlier observations affected the answer. Later tasks could require predicting movement outcomes and constructing action sequences using the same machinery.

The principal unsolved issue is efficient discovery. This proposal makes construction, memory, revision, and active observation concrete, but a useful candidate may lie beyond any affordable search. A second unresolved issue is whether the initial operations permit the abstractions needed for substantially different environments. Success on shapes would warrant testing those questions; it would not answer them.
