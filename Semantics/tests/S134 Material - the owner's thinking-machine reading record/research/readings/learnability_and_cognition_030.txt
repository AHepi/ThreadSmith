This section of Steven Pinker's *Learnability and Cognition* (file pages 316–324; printed pages 295–303) addresses how a child could learn verb meanings and argument structures despite circular dependencies between syntax and semantics.

**Breaking the acquisition circle.** Pinker considers two ways a child might identify grammatical functions before learning verb semantics. One relies on early phrase-structure assignments consolidated into grammar, later used to restructure verbs with noncanonical semantics (file page 316). The other, less demanding of input sequencing, combines multiple partially predictive cues—linear order, tree position, agreement markers, coreference, prosody—into a constraint-satisfaction conspiracy, possibly implemented in a symbol-passing network (file page 316). Either way, Pinker assumes some reliable identification of grammatical functions precedes learning of non-cognitively-given verb semantic structures (file page 316).

**Limits of universality: syntactic ergativity.** Linking rules are not fully universal. In syntactically ergative languages (rare, at most about 5 percent), patients link to subject roles and agents to object roles (file page 317). Pinker sketches—not solves—how this might arise: languages must map four thematic distinctions onto two case distinctions, and ergative morphology groups intransitive themes with transitive patients (file pages 317–318). A child learning such a language bends, rather than discards, the unmarked linking rules, keeping intransitive actor/theme-to-subject mappings while reassigning agents and patients to fit morphology (file page 319). He stresses this is a rough sketch, useful mainly to show that exceptions modify rather than abolish the central linking rules (file page 319).

**Event-Category Labeling.** The simplest verb-learning assumption is that verb meanings match preexisting perceptual-cognitive event categories: a child maps a sound to a concept exemplified in a situation (file pages 319–320). Pinker names this Event-Category Labeling and grants it plausibility for verbs like *have*, *hit*, *move*, *put*, *give* (file page 320).

**Semantic Structure Hypothesis Testing.** This suffices only for some verbs. Languages carve event flux differently; English *pour* and *fill* cross-classify the same events (file page 320). Ambiguity in one situation dissolves across situations: *pour* but not *fill* applies to half-filling a glass; *fill* but not *pour* to rain filling a windowsill glass—so a learner with memory across situations has discriminating evidence (file page 320). Pinker extends a hypothesis-testing mechanism from inflectional morphology: features drawn from a finite universal set are sampled, contradicted values permanently stricken, correct ones surviving in the limit (file page 321). For verbs, the representational scheme constrains hypotheses—place-functions and act-motion causation are codable; speaker mood, ambient temperature, or reminding relations are not (file page 321). Tentative embedding constraints yield a finite class of grammatically distinguishable verb representations, needing no causal chains longer than three links (file pages 321–322). Open-class elements like "butterlike" in *to butter* fill only permitted slots such as MANNER or PROPERTY (file page 322). Incorrect hypotheses are erased when contradicted in context; for *fill*, features like container shape, manner of causation, or liquidity get expunged across instances (file page 322).

**Practical constraints on learning speed.** Brute-force testing is plausible only with convergence aids. Semantic biases favor cohesive event scenarios; contrastive discourse (Carey and Bartlett's "chromium" example) narrows options; Clark's Principle of Contrast bars meanings identical to existing verbs, pushing learners toward manners, means, and object properties once light verbs consume simple combinations (file pages 323–324).

**Syntactic cueing.** Once grammar exists, argument phrases in the input directly reveal argument structure—Pinker's earlier "L1: Direct Learning from Positive Evidence"—but since argument structures project from semantics, backward linking must reconcile them (file page 324). Circularity is only apparent if syntax and semantics are deduced for the same entry simultaneously; staggered acquisition avoids this (file page 324).

**Engineering implications (distinct from Pinker's claims).** For a thinking machine, this suggests mechanisms worth testing: multi-cue constraint satisfaction for role identification, hypothesis elimination over a constrained representational vocabulary, cross-instance memory for disambiguating categories, and contrast-driven refinement. Pinker's results concern child language acquisition specifically; they do not establish universal learning laws, nor do they demonstrate that a non-neural symbol system suffices for general intelligence. Topics like emotion, analogy, or social cognition are not treated here.
