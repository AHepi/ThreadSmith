## Verdict on the frame problem

Steven Pinker, on supplied file page 12, does present the frame problem through Daniel Dennett's robot parable. The robot must fetch a battery from a room containing a time bomb. Version 1 pulls the wagon and fails to notice the bomb comes too. Version 2 computes all side effects and is destroyed while proving irrelevant facts. Version 3 tries to sort relevant from irrelevant implications and is destroyed while sorting. Pinker's conclusion, continued on file page 13, is that an intelligent being must deduce "only the relevant implications," and that this requirement is a deep problem for robot design and epistemology, which came to light when artificial intelligence researchers tried to duplicate common sense in computers. This is a faithful characterization of the frame problem as a problem of relevance and side effects.

## Verdict on specialized assumptions

Steven Pinker, on supplied file pages 20 and 21, argues that ill-posed problems become solvable when a system supplies missing information as assumptions about the world. His worked example is inverse optics: brightness alone cannot distinguish coal from snow, but a module assuming smooth uniform illumination can subtract brightness gradients and compare each patch to the scene average. He extends the argument to inverse kinematics, inverse dynamics, and intuitive psychology. On file page 22 he states the general claim that each mental module solves its unsolvable problem by "assumptions that are indispensable but indefensible," defended only by their past success in ancestral environments. This supports the weaker claim that task-appropriate assumptions help make underdetermined problems tractable.

## Verdict on an efficient general relevance algorithm

The supplied pages contain no such algorithm. File page 12 shows Version 3 failing precisely because it must enumerate and classify millions of implications. File page 13 says only that "somehow we all solve the frame problem." No mechanism, heuristic, or complexity analysis is offered. Claiming that Pinker supplies an efficient general relevance procedure would be an invention.

## Verdict on program enumeration plus active tests

Nothing in the supplied pages discusses program enumeration, hypothesis search, or active testing as a solution to relevance. File page 12 warns that computing all side effects is fatal, which cuts against any proposal whose cost grows with the space of possible implications. A claim that enumeration plus active tests "fully solves" the frame problem is therefore unsupported by this source and, given the parable's structure, in tension with it. Active observation may still reduce search in our design, but that is our engineering proposal, not Pinker's finding.

## Verdict on modularity and symbolic necessity

Steven Pinker, on file page 20, claims the mind is "a system of organs," which he calls psychological faculties or mental modules, and predicts on file page 22 that no humanlike robot will be built unless it is packed with computational systems tailored to different problems. However, file page 22 explicitly loosens the notion of module: modules need not be spatially circumscribed, need not be tightly sealed, and are defined by the special things they do with information. He notes that a computer program can be fragmented across memory. Nothing in these pages proves that one exact modular architecture, still less a symbolic one, is necessary. The pages support functional specialization of assumptions; they do not select a unique implementation formalism.

## Faithful paraphrase

Common sense cannot be stored as an exhaustive database, so a system needs core truths plus rules, yet even well-crafted rules leave the problem of which consequences matter. Dennett's robots show that ignoring side effects, computing all of them, and filtering them each fail in their own way. Separately, problems like inverse optics have no unique solution from the data alone, so a working system must add assumptions tuned to its domain, at the cost of brittleness when conditions change. Pinker infers that minds are built from many specialized parts, but describes those parts loosely, as functional rather than necessarily localized or sealed.

## What this supports and what remains

The source supports three design constraints: relevance cannot be free, task assumptions must be explicit and revisable, and specialization of processing is a plausible engineering strategy. It does not provide a relevance algorithm, a learning rule, a temporal memory mechanism, a compositional semantics, an active-perception loop, or a goal architecture. Those must be invented. Our proposal to use executable grounded representations, constrained generalization, temporal memory, and active tests is an engineering extension. It should not be presented as demonstrated human intelligence, as proof of consciousness, or as a validated general intelligence algorithm. Historical skepticism about particular programs on file page 22 concerns those programs and the hype around them; it is not evidence that all neural implementations are insufficient.
