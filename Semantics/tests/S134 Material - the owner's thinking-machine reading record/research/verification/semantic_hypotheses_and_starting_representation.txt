# Verdict on Semantic Structure Hypothesis Testing

**Mechanism and initial representation.** Supported. On file page 322, Steven Pinker describes a learner retaining a "maximal possible conceptual representation" of an event instance involving a verb, built from structures of the form of his chapter five semantic formalism. This representation contains many candidate relations, most irrelevant, with the correct verb meaning being some subset. File page 320 introduces the simpler precursor, Event-Category Labeling, where a verb is linked to a conceptual structure the child already formed from interacting with the world.

**Candidate semantic elements.** Supported with qualification. File page 321 states hypotheses are drawn from a finite universal set of grammaticizable features, each with a conceptual or perceptual correlate. File page 322 adds that representational constraints limit what can be encoded: place-functions and causal relations are expressible, but speaker mood, ambient temperature, and reminding relations are not. Open-class material like "butterlike" fills allowable slots such as MANNER or PROPERTY as dependents of determinate roles.

**Contradiction update and permanence.** Supported for the inflection-learning case, extended by analogy to verbs. File page 321 explicitly says a contradicted feature value is "permanently stricken from the list of hypotheses for that morpheme," illustrated by expunging [+human] upon a nonhuman referent. File page 322 says the verb case works by "permanently erasing structures that are contradicted by the current situation," giving container shape, manner of causation, and liquidity as examples for *fill*. So yes, deletion is permanent, in a batch-like setting of accumulating many usage instances of one morpheme or verb.

**Convergence assumptions.** Supported but explicitly qualified as brute-force. File page 321 assumes every feature in the finite universal set has nonzero probability of being hypothesized, so correct hypotheses appear eventually and only correct ones survive "in the limit." File page 322 concedes this accounts for acquisition "in a brute-force way" and is plausible only if convergence is reasonably quick. File page 323 lists practical constraints to speed this up: semantic biases from cohesive event categories, contrastive discourse contexts, and Herbert Clark's Principle of Contrast barring hypotheses duplicating another verb's meaning.

**What perception and innate rules supply.** Supported. File page 313 says linking rules are "essentially innate" and conceptual structures come "from the perception of the situations in which verbs are used," providing constraints outside language. File page 320 assumes the child can link verbs to conceptual structures on hearing them in an exemplifying situation, and that children and adults construe many events similarly.

**Circular dependency.** Supported and acknowledged. File pages 314 to 316 raise the worry that syntax is learned via linking rules from lexical semantics while some semantics is learned via linking rules backward from syntax, risking stable but incorrect mutually compatible structures. Pinker offers two circle-breakers: staged input with nonsyntactic filters, or combining multiple partially predictive cues (linear order, tree position, agreement, coreference, prosody) as constraint satisfaction. He assumes some reliable grammatical-function identifier exists before non-given semantic learning begins.

**Limitations admitted.** Supported. Brute-force convergence (file page 322), dependence on fast practical constraints (file page 323), and unresolved interdependencies deferred to other work (file page 315).

# Engineering Applicability

Pinker's contribution is a clean revision primitive: maintain a structured hypothesis set, test each component against instantiated contexts, permanently delete contradicted components, and rely on a finite constrained vocabulary plus biases to converge. This maps well onto a revisable-model module with inspectable state.

What the source leaves unsolved is substantial. The mechanism assumes already-segmented situations, already-formed conceptual elements, and a perceptual system that reports whether a structure is "currently instantiated in a concrete context" (file page 322). Noisy raw sensory data supplies none of this: we must invent grounding, segmentation, feature extraction, and a confidence or defeasibility layer, since real perception yields probabilistic matches, not clean binary instantiation tests. Permanent deletion is safe only under Pinker's clean-input assumption; noisy data requires reversible or weighted revision. Temporal memory across situations is assumed ("the right kind of memory across situations," file page 320) but not designed. Compositional reasoning, active observation choice, and goal selection are outside these pages entirely. The historical inflection work concerns specific linguistic representations and does not establish general learning laws or limits on neural implementations.
