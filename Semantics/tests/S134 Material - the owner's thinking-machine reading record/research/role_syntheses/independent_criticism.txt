The provisional architecture's central vulnerability is that its primitives may conceal the intelligence they claim to build. Steven Pinker's kinship production system stores the definition of uncle inside a demon's condition-action structure rather than deriving it (How the Mind Works, file pages 44 through 50), and he warns that treating difficulty, similarity, or salience as primitives is a "scam" (How the Mind Works, file page 55). Learnability and Cognition sharpens the threat: productive generalization over verbs depends on a supplied inventory of semantic elements such as cause, go, be, path, and have, plus linking rules mapping them to grammatical functions (Learnability and Cognition, file pages 107 through 109, 265 through 266), and the learner cannot recover these from distribution alone without re-raising the generalization problem (Learnability and Cognition, file pages 37 through 38). Pinker also dissociates primitiveness from constrainedness: not every arrangement of components is a licensed verb, so bounding search is insufficient (Learnability and Cognition, file pages 263 through 264). A decisive test is to give the machine unlabeled events of motion, contact, and state change and ask which novel descriptions permit caused-motion versus caused-possession rephrasing. Success without supplied primitives would exceed Pinker's argument; failure would show the answers were hidden in the design. This would falsify one implementation, not computational theories of mind generally.

Grounding raises a second objection. Inverse optics is ill-posed: an elliptical image could be an oval head-on or a circle at a slant, and a gray patch could be shaded snow or sunlit coal (How the Mind Works, file pages 126 through 127). Vision becomes solvable only by adding premises about how the world is on average put together (How the Mind Works, file page 127), with distinct assumptions in shape, lightness, shading, and stereo analysis (How the Mind Works, file pages 138 through 139, 143 through 149). So "calibrated sensor records" cannot be neutral transduction; either the machine receives many assumptions or it cannot perceive at all. Rival mechanisms the source leaves open include constraint-satisfaction networks where tentative matches negotiate (How the Mind Works, file pages 138 through 139) and Adelson and Pentland's cost minimization across shape, lighting, and reflectance experts (How the Mind Works, file pages 147 through 155). Presenting an Ames room or a bistable fanfold would reveal which assumptions are built in and whether competing interpretations persist; a single committed model predicts no depth flipping. Reference frames are another silent prerequisite: retinal coordinates fail once the eyes move, and head-, body-, world-, gravity-, and object-centered frames each require machinery (How the Mind Works, file pages 155 through 159). Training on one orientation and testing another distinguishes mental rotation, stored views, and object-centered recognition, since people use all three (How the Mind Works, file pages 164 through 165).

Compositionality is the hardest structural objection. A network with active units for baby, ate, and slug cannot distinguish "the baby ate the slug" from "the slug ate the baby"; roles must be bound explicitly, and even concept-role pairs fail on the four same-as and different-from propositions without a proposition-level layer (How the Mind Works, file pages 73 through 76). Pinker notes that predicate, argument, and proposition machinery must be "snuck back in" (How the Mind Works, file page 75). Two identical circles that briefly superimpose must remain two individuals, and co-location does not merge identity (How the Mind Works, file pages 71 through 73). In language, narrow classes turn on what a verb constrains rather than what typically accompanies it: hit specifies motion plus contact, cut adds effect, break specifies effect alone (Learnability and Cognition, file page 145), and throw verbs differ from pull verbs in whether causation is instantaneous or continuous (Learnability and Cognition, file pages 277 through 278). A machine representing kissing as approach plus contact will wrongly license "kiss at" (Learnability and Cognition, file pages 143 through 144). Swapped-role scenes and novel verbs differing only in instantaneous versus continuous manner test binding and narrow-class discovery; success requires naming the binding and matching mechanisms, since Pinker admits the matching function is unspecified (Learnability and Cognition, file page 270).

Temporal memory and blame assignment remain largely unsolved. Visual memory is fragmentary: subjects recalled a median of three of eight penny features, half misplaced (How the Mind Works, file page 173), and whole scenes cannot be reconstructed (How the Mind Works, file page 174), so complete snapshots are wrong. Strategic memory is stricter: reciprocal altruism requires remembering who helped and who refused (How the Mind Works, file page 236), and friends track gifts and invitations to reciprocate (How the Mind Works, file pages 292 through 293). Learnability and Cognition adds aspectual structure: states are unbounded regions, instantaneous events are points, accomplishments are bounded regions (Learnability and Cognition, file page 262), and rules must inspect this structure (Learnability and Cognition, file page 472). Delayed queries about central versus peripheral detail and exchanges with multiple partners would separate episodic, strategic, and aspectual stores. When a failure is ambiguous between perception and rule error, observing which component the machine revises tests blame assignment; random or global revision indicates unconstrained search. Pinker's own hypothesis testing is admitted brute force (Learnability and Cognition, file pages 322 through 323), and he concedes vicious circles where syntax and semantics must be learned together (Learnability and Cognition, file pages 314 through 316).

Search and generalization need constraints stronger than bounding. Any true statement spawns infinitely many useless ones, so an inferencer must guess which implications to explore (How the Mind Works, file page 195); Dennett's robot versions fail by ignoring side effects, proving everything, or classifying relevance while the bomb ticks (How the Mind Works, file pages 12 through 13). Conceptual clustering for narrow classes is computationally explosive and some nonalternating subclasses are tiny (Learnability and Cognition, file pages 340 through 341). Pinker's replacement, parameterizing idiosyncratic lexical information, yields Color-Blind Conservatism, which he then weakens because verbs within a class differ in grammatically relevant ways (Learnability and Cognition, file pages 343 through 350). His notes concede that motivated categories overgenerate and must sometimes be listed (Learnability and Cognition, file page 465), that effect-plus-means specifications block causativization (Learnability and Cognition, file pages 467 through 468), and that a property-binding constraint is stipulated because the learning account requires it (Learnability and Cognition, file pages 472 through 473). Time-pressure tasks with mostly irrelevant implications and exception-laden classes would distinguish bounded construction, case-based retrieval, production systems, and constraint satisfaction; convergence growth would show whether practical biases do real work.

Goals cannot be static priorities. Samaritan robots illustrate that even self-sacrifice requires complex discrimination (How the Mind Works, file pages 14 through 15), and emotions dynamically install cascades of subgoals (How the Mind Works, file page 218). Anger, gratitude, and guilt calibrate social commitments (How the Mind Works, file pages 236 through 237), while doomsday machines show that irreversible commitment can outperform continual rational revision (How the Mind Works, file pages 238 through 242). Self-deception may maintain a distorted record for presentation and an accurate one walled off (How the Mind Works, file pages 246 through 248). Conflicting-goal scenarios and bargaining tasks would test context sensitivity and commitment credibility; always-updating machines predict exploitation. These findings are domain-specific to social and linguistic cognition and do not automatically transfer to general learning.

The strongest rival left open is a hybrid: constraint satisfaction and pattern completion for perception, structured role-bound representations for composition, case-based retrieval for episodes, and content-specific inference rules for relevance. Pinker treats neural networks as a parts catalogue for demons (How the Mind Works, file page 71) and allows multidimensional semantic spaces (Learnability and Cognition, file page 215), while criticizing particular connectionist models rather than all networks (Learnability and Cognition, file page 440). Comparing purely symbolic and hybrid systems on noisy recognition plus nested role binding would discriminate them. None of this establishes consciousness; Pinker separates access and self-knowledge from sentience and says the computational theory offers no clear answer to sentience (How the Mind Works, file pages 82 through 84). The apparatus sections of both books are bibliographic and cannot verify arguments; the flow diagrams at Learnability and Cognition file pages 447 and 448 are fragmentary and unverified. No machine has been built or tested here, so every mechanism above remains engineering conjecture, and success on shapes or verbs would not demonstrate general thinking.
