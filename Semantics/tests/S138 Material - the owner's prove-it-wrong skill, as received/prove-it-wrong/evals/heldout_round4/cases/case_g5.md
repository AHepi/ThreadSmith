# case_g5

Personalised pricing pilot — November run

We ran a four-week A/B test from 3–30 November on the UK home-goods store: returning visitors flagged as price-sensitive (cart-abandon history) were shown a 10% voucher banner at checkout; control saw none. The split was 50/50 by account ID, roughly 180k visitors per arm. The primary metric at design time was revenue per visitor; conversion rate was secondary. Halfway through, the revenue metric crossed significance (p<0.05) and, with Black Friday approaching, we stopped the test early and rolled the banner out. Final numbers: revenue per visitor +6.4% in treatment, conversion +2.1 points, p<0.05. Gross merchandise value is taken from checkout totals at the time of order. We did hear anecdotally from support that the voucher code was circulating on a deals forum in week 2, so some control users probably found it too, which if anything makes our estimate conservative. Marketing spend was unchanged. We propose extending personalised vouchers to all EU stores with an expected +5–6% revenue lift.
