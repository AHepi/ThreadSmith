# What Avida needs to learn from outside data

Execution of Brief 01, 2 October 2026. Source version: `devosoft/avida` commit `47f13dadb547fcf10f620ace60247f38b30b8b16`. Method: hard-to-vary, with separate semantic, source-code and experiment-design reviews.

**For the owner**

Learning from outside data needs a way for that data to change what the system keeps, and a way to use what it keeps later. Simply feeding in numbers does not establish learning. A second sensor and actions that change the source can help, but neither is always necessary.

Avida already has input, computation, variation, copying and reward mechanisms. Its existing event system can carry an encoded recording into the simulation. What remains to demonstrate is that the recording changes a retained ability that works on unseen data, rather than rewarding a shortcut.

The proposed seven connections mix several different jobs. They also omit an explicit link from source-dependent feedback to retained change. Under the supplied semantics, improved performance alone does not establish representation. That requires a separate check of structure and history.

**Hypothesis and what would count against it**

For this brief, I hypothesize that the whole Avida execution environment can acquire a retained, source-dependent capability when an external observation or consequence reaches a variable candidate system, affects what it retains, and can affect later behaviour on a stated task. Direct input to each program is one route; external consequences changing selection are another. Continuous fresh input, an independent second sensor and an action loop are not universal prerequisites. This is an enabling hypothesis, not a promise that every dataset, instruction set or run will learn. Against a claimed instance would be unchanged retained capability after cutting every source-to-update route throughout acquisition while fixing the initial state and excluding prior source-specific capability, equal apparent gain with source feedback replaced by a source-independent control, or a gain explained entirely by a current input, exposed answer, clock or supplied lookup table. A finite failed search does not by itself refute this enabling claim. It can challenge only a separately stated claim about success within a specified budget or across a specified run distribution. None of these observations alone decides which background assumption failed.

**Scope and evidence status**

The learner under test is the whole simulated world, as the owner requires. Programs are its variable material. The proposed tests must state separately whether an external driver is included in the learner boundary; neither attribution is chosen for the owner here. A recording has an outside origin even after its bytes are loaded into the simulated world. It then supplies recorded evidence, not a continuing connection to the original process.

The question is what connections make retained learning from an outside source possible, and which connections the inspected code supplies. The working success criterion is a source-dependent, retained change that improves performance on a predeclared task and held-out cases, with source-independent selection and pre-learning controls. This is an added operational criterion for these experiments, not a definition of knowledge, explanation, construction or autonomy.

**Corrections that change the answer**

The default three-number cycle is a configuration, not Avida's entire input capability. `SetupInputs` also accepts specified inputs and has other modes. `SetEnvironmentInputs` takes three integers with prescribed high bytes, applies them across the population and resets input buffers. A driver can therefore encode a pre-existing physical recording into an events file without changing C++. That supplies a data route; it does not supply a next-sample evaluator or demonstrate learning. [checked: C1–C3]

Default split division resets ordinary CPU state when epigenetic inheritance is disabled. It does not mean that only the instruction sequence passes on: the default configuration also inherits merit, and optional modes retain or transfer registers and a local stack. Ordinary working memory already exists during execution; the reported history patch supplies history-dependent tasks and input frames, rather than establishing that stock programs had no memory. [checked: C7; patch role reported in shared context, lines 115–117]

The list mixes transports, causal mechanisms and restrictions on candidates. L4 is initially an evaluation/retention mechanism; L7 specifies which candidate transports are admissible. Neither is automatically a transport in the semantics' sense. A C++ function is not enough: the organizations, valuation map, edit map, boundary map and component correspondence must be supplied. [worked out from Sem 83–105, 181–189]

The composite “L1 then L3” is not typed as written: L1 ends in input states, while L3 begins with a program organization. Execution, initial state and sampling must connect those endpoints. Moreover, the place numbers came from does not settle what a program represents. A circuit computing NAND on inputs is not thereby a model of the random generator that supplied them. [worked out from Sem 183–213; checked: C1, C4, C5]

Higher replication success is weaker than D12.1. That definition asks for a survival condition requiring fidelity on an encountered history, as well as the absence of an earlier representation of the transport, history, survival condition or codomain, and the absence of a construction trace. Stock task rewards can alter success while programs that do not perform a task still replicate; stock configuration has optional task requirements, but these are not automatically fidelity requirements over every member of a fixed history. Reading A therefore remains conditional, not an automatic label for every evolved program. [checked: Sem 195; C6, C7]

Withholding pay is selective feedback, but not automatically Gold's informant. An informant supplies membership classifications for strings; stock pay can be absent because of task failure, reaction prerequisites or resource conditions, and the default heads instruction set does not explicitly report membership labels. Gold's positive-data limitation concerns specified language classes and eventual identification: it does not prohibit every restricted class containing an infinite language. [checked: Gold, pp. 450–453; C6, C8]

Argument 3 says that an unseen value is left open **when an admissible alternative survives the same history and differs there**. It does not say that data have no role in generalization, or that every unseen value remains undetermined. A candidate restriction together with the data can settle unseen values. [checked: Sem 570–576; Pinker 2004, pp. 949–950]

Finally, equal performance on external and internally generated streams tests an advantage claim, not the claim that an outside source is necessary for any learning. An inside-only condition exhibiting retained improvement under the same origin-neutral learning criterion would address that necessity claim. Identical observations, feedback, initial states and random choices give identical execution under the same transition rules, whether the observations were loaded from a file or replayed internally. Matching a few summary statistics is much weaker than matching this entire input history. [worked out; correction to H5 in shared context, line 145]

**The composite and the smallest necessary set**

The stock acquisition path is generator state and sampling → cell values → input register/buffer. Execution then depends on the instruction sequence and current machine state. For semantic composition, lift these into compatible organizations and include that execution bridge before attempting a carrier-to-content transport. The intermediate scopes must agree. Without this repair, L3∘L1 is not defined. With it, the acquisition path originates in the internal generator, but this still does not make its content the generator. A task circuit may carry a Boolean relation. A prediction of generator dynamics would require an additional claim with a corresponding contract. [checked: C1–C5; worked out from Sem 183–189, 353–365]

For a retained capability learned from an outside source, the indispensable causal jobs are an entry route for source-dependent distinctions, an admissible mechanism capable of changing a relevant behaviour, a route by which those distinctions affect the change retained, and later use of that retained change. Retention may be carried by instruction sequences and population composition, by working memory, or by selector state. The seven-row list needs the **source-dependent update-to-retention connection** made explicit. Evaluation-to-retention is its implementation in the proposed Avida selection route; explicit evaluation is not a universal prerequisite for every possible learning mechanism. An input route and an output route with no such connection can merely run the same fixed computation forever.

There are two routes for the entry job. Source observations can reach program inputs and affect evaluated behaviour. Alternatively, program outputs can be judged through an external consequence that changes which programs are retained, even when the programs never receive the raw source observations. Remove both routes and there is no new causal dependence on that source, unless an earlier source-derived state was already present. Such a state must be counted as prior evidence rather than as learning with no source history.

For the proposed stream-prediction experiments, the minimal functional arrangement is therefore L1 plus execution/working state, L2's output route, source-dependent L4, and a retained update within the admissible candidate/variation structure described by L7. L3 is the candidate correspondence being assessed, not an additional piece that must be fully formed before learning can begin. L5 and the strong semantic reading of L6 are optional; the operational reading of L6 belongs with L7. If the desired result is representation under (R), add the carrier-to-content fidelity and provenance requirements. If the desired result is strict prediction, add the object/simulation-layer requirements. Neither stronger requirement is established by generic learning performance.

This is a minimal set of causal jobs, not a unique number of software modules or a sufficiency theorem. The source must contain a task-relevant distinction, candidate behaviour must be capable of using it, and variation and selection must be able to reach and retain that behaviour. A source can be external and still be irrelevant or unlearnable under the chosen contract.

The whole account has a discriminating rival: apparent learning may come from exposed future values, repeated addresses, tagged input positions, a clock, inherited evaluator state, or rewards unrelated to the target. Cutting all relevant alternative source-to-update paths during acquisition must remove the claimed new source dependence. A content-preserving recoding should preserve behaviour only when the corresponding state, decoder, timing and resource conventions are carried across as well. Changing only a displayed score must not count as changing learned ability. These are the useful poke/reverse tests; success and failure are not both accepted as evidence of the same learning claim.

The interaction to watch is richer input versus a wider attribution. A second channel can reduce ambiguity while supplying the answer or a prior representation that changes the semantic history. More candidate freedom can permit a useful program while also admitting incompatible continuations on unseen cases. Restricting the class can fix those cases while excluding other capabilities. These effects must be reported at their actual layer, without rescuing a failed run by quietly redefining its task, boundary or candidate class.

**Five proposed tests**

All five tests below are **worked-out proposals, unrun**. The source and semantic checks above revise the brief before any experiment is frozen. A later implementation should freeze one canonical protocol, develop the adapter on one diagnostic case, retain its first outputs, and log any later change as a change to the candidate, rig or input preparation. A successful self-authored diagnostic is not an independent learning result.

Across tests, freeze data provenance, split boundaries, encoding, pay, budgets, seeds, reset policy and outcome definitions before search. Use complete held-out episodes or long contiguous stretches, separated from training by more than the permitted context and forecast horizon. Preprocessing and surrogate fitting use training data only. No future values, centred filters, test labels or held-out scores enter selection. At evaluation, freeze instruction sequences, disable variation and task-dependent selection, and use a predeclared population sample, such as 100 occupied positions per run with an explicit rule for empty worlds. Report the sampled-program share above a fixed comparator margin and abundance-weighted accuracy. Runs are the independent replication units; cells are not independent experiments.

For stream prediction, present a frame, accept one irrevocable answer before its target becomes available, then reveal/score the target. An IO call made before consuming the current frame is unscored; the eligible answer must follow consumption of every required input slot in that frame. A timeout earns no predictive reward and remains an attempted frame in the denominator. Keep unscored warm-up frames separate. Repeated reads and multiple guesses must not advance the source or buy extra scoring attempts. Fix source time independently of program read count. Declare how replacement, division, end-of-file, missing frames and evaluation warm-up affect the cursor. Use separate random streams for source generation and program variation/scheduling. Otherwise changing execution can silently change the supposedly matched source.

Require current-value/persistence and training-only frequency comparators, starting-program evaluation, and an independently written virtual program that can perform the task where such a witness is available. These distinguish an unlearnable target or broken interface from search failure. A planted witness is a rig check, not an evolved result. Report both instruction-sequence retention and any dependence on retained working/selector state through separate resets.

A proposed `EXTERNAL_STREAM_MODE=0` flag can gate the new adapter; the name is a design proposal, not an existing option. Disabled behaviour must remain the stock path. Implement framing and target hiding near `Inst_TaskIO`. In enabled diagnostic modes, the dedicated scorer replaces ordinary logic-task setup and unrelated task reactions, then returns through the intended reward path; it must not fall through and collect stock logic rewards as well. `cEnvironment::TestOutput` invokes `cTaskLib::SetupTests`, whose assumptions about bit combinations make arbitrary scalar substitution unsafe without an appropriate gated path. The existing event route is sufficient for transporting encoded data, but not automatically for enforcing this forecast protocol. Do not assume S119 already handles these issues: its source was not supplied. [checked integration locations: C4–C6; worked-out design]

**Test 1 — Outside recording, matched internal source and shuffled recording**

Use a physical record collected for another purpose. One concrete candidate is the [BIDMC PPG and Respiration Dataset v1.0.0](https://physionet.org/content/bidmc/1.0.0/), whose data page describes 53 eight-minute hospital recordings including pulse, respiration and ECG signals. Only the documentation was opened; no signal file was downloaded or analyzed. [checked: dataset, Data Collection/Data Files]

A concrete pilot could use recording IDs 01–04 for training, 05 for protocol validation and 06–07 for final evaluation, chosen by this ID rule before inspecting task performance. Freeze causal downsampling, for example every 25th PPG sample from the documented 125 Hz signal, and eight quantization bins fitted on the training records. Predict the next bin, one 0.2-second step later. Direct decimation may alias the underlying waveform: the claim is about this defined 5 Hz observation stream, not recovery of the full physiological signal. Exclude cross-record boundaries when estimating the surrogate transition law as well as when scoring forecasts. Reject missing/corrupt records by a predeclared data-integrity rule, not poor predictive results; preserve the exclusion. For the pilot, advance one global source frame per Avida update, independently of reads. Traverse training recordings in ID order and repeat only that training sequence until the update budget is exhausted. Do not score a transition across record boundaries; send an episode-reset marker and use the same unscored context warm-up in every arm. Reset adapter cursors and frame eligibility, without restarting replication or silently erasing virtual CPU state. These choices are a starting diagnostic, not evidence that this horizon, rate or encoding is learnable. At a short horizon, persistence is a consequential rival.

Run four arms: original training recording; internal first-order Markov stream whose transition probabilities and initial-bin frequencies are estimated only from training data; the training recording shuffled within training partitions; and original recording with an answer-independent reward schedule drawn from the already budgeted answer-contingent arm for the same seed, with donor episode/timing independently permuted before the yoked arm starts. The yoke should preserve reward scale while breaking dependence on this program's answer; record any resulting exposure/resource mismatch. This is a control for answer contingency, not automatically for every source correlation. Audit residual source/reward correlation and do not describe it as source-independent merely because the answer is ignored. A simple unpaid control is an alternative whose changed resource budget must be reported.

Evaluate every frozen population on the same untouched external recordings. Also report its own-source held-out performance as a diagnostic, not as the main transfer comparison. The internal surrogate is fitted to the stated statistics, not every feature of the physical record. Finite samples need not match the empirical counts exactly. Report marginal and one-step discrepancies using a diagnostic threshold fixed from training-only simulations before learning; do not choose a surrogate after viewing held-out performance. Separately, replay a byte-identical framed transcript through file and internal adapters with identical learner random choices. That adapter null should give identical execution; it is not a fifth evolutionary arm.

The conditional expectation is an original-record advantage only if it contains exploitable structure absent from the surrogate and accessible to the candidates. An advantage over shuffled and yoked controls supports use of source-dependent structure, not a special benefit of physical origin. No advantage over the matched source counts against the claim that the unmatched source structure matters for this task. A difference in the byte-identical null counts against the rig. Failure in every arm remains ambiguous until the planted predictor, baselines and framing pass their diagnostics. A gain that vanishes on new recordings is record-specific performance, not the claimed wider transfer.

This needs a small off-default recorded-stream/scoring integration for the specified protocol, plus a file-preparation driver. Four arms × four seeds × 20,000 updates at 3,600 cells costs **5.6 nominal CPU-hours** at the supplied rate. Data preparation, adapter diagnostics and frozen-program evaluations are additional and untimed.

**Test 2 — What the candidate population leaves open**

Use a dedicated scalar task. Provide two bits x and z and pay only on H = {(0,0), (1,1)}, with outputs 0 and 1 respectively. The candidate behaviours f(x,z)=x and g(x,z)=z agree on every paid case and differ on the off-diagonal cases. Before drawing an Avida conclusion, implement both as virtual, replicating programs and check their execution under the same state, time and variation constraints. A mathematical description of them is not yet an admissible-program witness.

Use two task-free, replication-matched ancestors with the same instruction set as the two evolutionary conditions. **Test 3 — Positive-only evidence and retreat from excess acceptance**

The brief's literal reward-on-generated-positive proposal is replaced openly here. It still disadvantages extra outputs through missed reward and execution cost. Instead, let a program output an acceptance bitmask A for a small universe U={0,…,7}. Each program commits one mask before the next scored batch of items is revealed. The mask stays locked throughout that batch and its no-pay diagnostic probes; it cannot depend on the item currently being scored. Training then presents only positive items i, and pays exactly when bit i of the committed mask is set. Extra set bits are neither read nor charged by the scorer. At equal positive behaviour and execution cost, A and every superset A′ receive identical pay on the same positive history. A program accepting everything is the required adversarial control.

Use four arms: unrestricted positive coverage; positive coverage through a declared restricted decoder; explicit positive/negative membership feedback; and positive exposure with answer-independent yoked pay, using donor tapes from the already budgeted unrestricted answer-contingent arm and independently permuted episode/timing. The same residual-correlation caveat as Test 1 applies. One concrete restricted family is the six masks {u: bit k of u equals b}, for k∈{0,1,2}, b∈{0,1}. Select the target by a fixed rule, for example bit 0 equals 0, after publishing the family. First present positives 0 and 2; later introduce 4, keeping 6 entirely held out. A rule using bit 2 can fit the early positives yet accept unwanted items and reject the new positive 4. That positive can exclude it within this family; 6 remains a transfer test. This is a declared feature-based prior; the unrestricted all-accept mask remains unrefuted by positive membership data. Counterbalance feature recodings in diagnostics, carrying the family along with the recoding. Independently permute the six rule-code assignments before each run so code zero does not systematically name the target. Record the initial mask: a run with no measured excess acceptance initially cannot be reported as a retreat from it.

At fixed checkpoints, test isolated copies on held-out permitted items and disallowed items. These probes must not alter the evolving program, merit, subsequent stream or selector state. A retreat means fewer false acceptances while retaining acceptance of new permitted cases. Accepting nothing, emitting less, losing replication or memorizing the paid items does not meet that criterion. State whether the change is within one lifetime, a lineage or the population.

The expected unrestricted result is no direct selective pressure against extra accepted items when costs and positive behaviour match. Drift and program efficiency can still change the mask. The constrained arm can exclude a candidate that overaccepts some items while failing a newly observed positive; this does not let positives reject a strict superset of the target. The explicit-feedback arm checks whether the available programs can respond when exclusion information is provided.

Against positive-only neutrality would be differing training pay at matched execution cost for two hypotheses identical on every observed positive but different only on unobserved items. That exposes leakage or a hidden penalty. An execution-cost difference is separately a broken neutrality control, not evidence supplied by positive labels. Against a claimed prior-free recovery would be its dependence on the restricted decoder, compression preference or a reward budget penalizing extras. Changing only hidden negative labels must not change training. This finite experiment does not resolve Baker's paradox for human language or test Gold's eventual-identification theorem. [worked-out design; Gold scope checked above]

The new positive-coverage scorer, locked pre-item mask, restricted decoder and isolated probe mode should each be explicit, off by default. The decoder is an experimental change, not a property inferred from stock Avida. Four arms × four seeds × 20,000 updates costs **5.6 nominal CPU-hours**, plus the unpriced equal-cost and no-leakage audits.

**Test 5 — Outputs change later data**

State the boundary before calling the source outside. One formulation is s(t+1)=F(s(t),a(t),w(t+1)), with source state s, action a and outside influence w; w need not be random. Moving an internal rule into another file or process does not establish this substantive outside-source condition.

There are two separately costed options. **What this leaves open and the next step**

H1, understood as “whatever these programs can learn must be about Avida's code,” does not follow from their reliance on Avida instructions. A source-dependent correspondence could have an outside codomain while still being implemented by those instructions. Establishing that instance requires the source/content map and history; no such instance was run here. Under A, selected representation remains conditional on all of D12.1 and fidelity. Under B, a faithful correspondence may remain declared, while the operational retained-learning result can still be measured. These are different predicates.

H5 in the brief is “learning begins only with an outside source.” Retained improvement on an inside-generated task under the same origin-neutral criterion would address that necessity claim. The stronger claim that learning needs a continuously fresh outside stream is separate: replay of a previously acquired record challenges continuity, but retains an outside history and therefore is not by itself a countercase to original H5. Access to a particular outside source, directly or through earlier source-derived information, is the narrower causal entry requirement stated above. No experimental ruling on H5 is claimed here.

The consequential next preparation step is to freeze one short source/forecast/pay transcript and check it through the proposed adapter with an executable virtual predictor and a byte-identical internal replay. Include the tagged-input and one-answer-per-frame checks. This determines whether an apparent learning result could be produced by the rig before any costly evolutionary block is chosen. It does not need the owner to settle the definition of knowledge, A versus B, or the overall choice of environment.

The hard-to-vary result is a revised, testable connection account with explicit missing evidence. It is not an attribution of explanation, construction, universality or grade 3 selection to Avida. All experiment outcomes remain open.
