## 2. The bin

- Sentence 1, “when,” supplies temporal association. Time beyond chain order is outside the language, and “when” is not silently strengthened into “because.”

## 3. Words I split

None. “Caught fire” and “burned” are read literally. STRUCK is kept as the source verb and is not replaced by HIT to obtain a shape-book entry.

## 4. Readings I chose

The explicit second sentence fixes the literal-combustion reading. I treated the main clause “The kingfisher caught fire” as CLAIMED and the temporal subordinate clause “a spark struck its feathers” as GIVEN background. I used Facts for the two combustion descriptions because the source does not say that the strike produced either one. A causal Result would require the filled-in claim “as a result of happening p,” which I did not add.
