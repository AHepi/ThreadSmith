# L66 audit package

Start with **L66_AUDIT.md** for the findings, evidence boundary, component tests, whole-report checks and proposed acceptance tests.

**ANSWERS_ChatGPT.md** contains the complete report-only read-back for P01–P18 in the format requested by the reader brief.

**audit_protocol.md** records the expectations fixed after inspecting P01–P04 and before inspecting P05–P18. It does not claim a blind evaluation or a fresh checker execution.

**sources/** contains exact copies of the supplied reader brief and the eighteen printed reports. Links and line references in the audit refer to these copies. **sources/SHA256SUMS.txt** records their content hashes.

**evidence_index.json** is a navigation aid to selected diagnostic and consequence lines; it is not an evaluation score.

No source passages, original ledgers, rules or executable checkers were available in the supplied reader bundle. Conclusions about their correctness remain untested.
