## What is built (the new versions, each a new file beside the old, each with a give-up line)
**The driver, second version**, `rigs/rig 1 - arguments/patched/run_check_2.py`, from `run_check.py` (SHA-256 eff1dee15bebc977...), with these changes and no others:
- D1. The world a query runs in is an argument of `run_query`, required; the module global goes. *Gives up:* every caller changes.
- D2. Inside every named case, told or supposed, every check is run with the world looked at alone (checks 1 to 5, patches 8 to 11, 13, 14), printed under the case's heading. A finding inside a case that needs a line from outside the case is counted, not printed: "N findings inside 'x' needed a line from outside it". *Gives up:* run time; false alarms inside worlds from missing background, which the count is there to show.
- D3. The what-if block prints every line set aside, the BECAUSE line that tied it, that BECAUSE's own verdict from check 2 (FOLLOWS, JUMP, CIRCLE, IDLE, or not reached), and the note 38 line 113 promises wherever a line used was not written by the writer. The verdict rule does not change. *Gives up:* report length.
- D4. Every finding names at least one line in the one fixed form (line id, mark, sentence, text): the heads of BECAUSE, SINCE, PLAN and DENIED BECAUSE findings carry it; JUMP lists the claim line, the cause's lines and the effect's direct lines; NO CONNECTION lists the SINCE line, the reason's lines and the expected's lines; CANNOT TELL lists the plan line; chain rows carry the sentence; the what-if heading names its own line where the ledger gives one. *Gives up:* report length; a JUMP may over-name.
- D5. The NO FAULT FOUND header is replaced by an outcomes block: for each check, "asked, nothing found", or "not asked: the ledger has no line of that kind", or "ran out of time". *Gives up:* the one-line header.
- D6. A contradiction inside a told world is printed with told-world wording, not supposition wording.
- D7. The gauge prints, beside the old line relabelled "bin entries", three counts: distinct sentences with a bin entry; sentences that reached neither a line nor the bin; filled-in lines against said. *Gives up:* all three rest on the translator's sentence fields, unchecked.
- D8 (F15). Where a BECAUSE claim and a denied BECAUSE share both effect and cause, print "YOU CLAIM AND DENY THE SAME CAUSE", naming both lines. *Gives up:* a writer who denies a cause "in a different respect" is flagged; 38 has no respect field yet.
**The language, next version**: `authority/L80 The ledger language - complete definition, second version.md`, from 38 (5f0f54c2f6af60e5...), changed only by: a sentence saying rig 1 answers the commitment question and the world question is rig 2's; the told-world and supposed-case paragraph extended to every finding, with the outside-line count; a sentence on what a what-if answers; the outcomes block in the report's promised contents; F15's rule; rule 3 restated as required ("every thing in a happening has a thing line"). *Gives up:* one report section becomes two; the world half is not built this round.
**consequences_2.py** in tools, from consequences.py (782047f829cf6b39...): the world as an argument, one section per world; a found fact is "stated" when some justification for it uses exactly one line; `depends` and `depends_on` printed once; "no change in the reported fact set"; every line cited in the fixed form with its sentence. *Gives up:* the old regex; the old "nothing changes" wording.
**sameness_2.py** in tools, from sameness.py (9bb0534553397401...): a NOT on one side only breaks a near pair and is printed under OPPOSITE; exact match on token multisets; the buckets partition the lines; a near partner is consumed. *Gives up:* the old counts, which overlapped.
The old files are untouched and stay runnable.
