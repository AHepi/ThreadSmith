# The owner's word

Work is planned, the plan is shown, and each phase waits for the owner's word before it starts. A run started before the owner has seen the plan is a failure of this skill, whatever the run finds (HV Lesson 40). The owner's words are recorded as written in the Decisions file of the project they were said to; a routine choice made by the agent is never recorded there.

Some things are never run without the owner's explicit permission, whatever the plan: a Fable 5.1 reader under test; a Fable 5.1 or Opus 5 subagent. A key given by the owner goes into the environment for the run and into no file, and the owner is told to rotate it afterwards.

Where these came from: root conventions; HV decisions 38, 39, H2 to H4; Lesson 40.
