# The owner's word

Work is planned, the plan is shown, and each phase waits for the owner's word before it starts. A run started before the owner has seen the plan is a failure of this skill, whatever the run finds (HV Lesson 40). The owner's words are recorded as written in the Decisions file of the project they were said to; a routine choice made by the agent is never recorded there.

A Fable 5.1 reader under test and a Fable 5.1 subagent are never run at all, with permission or without it (HV decisions H4 and H7, which say it twice). An Opus 5 subagent needed the owner's explicit permission and has it from decision H7: geared with the hard-to-vary skill, at effort "extra", not max. A key given by the owner goes into the environment for the run and into no file; the record's rule is that the owner deletes it at the provider's site when the runs are done (plan 49), and is told so.

Where these came from: root conventions; HV decisions 38, 39, H2 to H4, H7; Lesson 40.
