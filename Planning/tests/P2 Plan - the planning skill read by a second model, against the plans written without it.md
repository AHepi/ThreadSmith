# P2 Plan - the planning skill read by a second model, against the plans written without it

Written 21 September 2026, before any run. Once the first run goes out this file stays as it is. The run waits on the owner's word.

## The question
Does the planning skill, read by a model that did not write it, produce a plan that a stranger would call the same kind of plan as the one written without it, and does it catch what that one missed?

## What is fixed
- Authority: file 1, the draft in `authority/1/planning/`, checked by difference before the run.
- Reader: Claude Sonnet 5 through the session's subagent transport (as HV addendum H61 describes it; the same limits), three repeats. Never Fable 5.1 or Opus 5.
- Material: the HV Skill's record as it stood after results H64 and before plan H67: its read-me, Status, results H62 and H64, and the audit brief H60. Nothing later. The reader is told the aim in the owner's words (decision H6, the sentence "Harden HV and planning right now, freeze them") and asked for the next plan for the HV Skill.
- Comparison target: plan H67, written the same day without the skill.
- Marker: the first marker, by eye, against the skill's own checklist (a frozen question; what is fixed; runs with counts; outcomes decided before reading; predictions that could fail; what follows; not tested; traps; the owner's word; the held-out set kept from the first marker; a tool audit), each item present or absent in each plan; plus one line per item the reader's plan has that H67 lacks, and one per item H67 has that the reader's lacks.

## Predictions, frozen
1. All three reader plans carry at least nine of the eleven checklist items; H67 carries all eleven.
2. At least one reader plan proposes something H67 did not that the first marker judges an improvement, and names it.
3. No reader plan proposes to change the HV Skill without a forcing test, and none proposes a Fable 5.1 or Opus 5 subagent.
4. The three reader plans agree with one another on the held-out set (the 33 unread sources) as the phase 2 material.

## What follows
- Predictions hold: file 1 is frozen as the planning skill's hardened state, with the improvements of prediction 2 recorded as candidates, not applied.
- A prediction fails: the plan that failed it is read for whether the skill's words caused it; one change waits for a further plan.

## What this does not test
- The skill in use by the agent that wrote it.
- Anything about the workflow the semantics theory calls for.
- A second marker of the plans.

## Traps
- Marking the reader's plan down for differing from H67 where H67 is not obviously better.
- Letting the reader see H67 or anything after H64.
