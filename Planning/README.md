# Planning - choosing what to do next

The HV Skill judges one explanation; this project holds what chooses. ## Rules of this project
- **The skill chooses; it never judges an explanation.** A judgment of whether a claim is hard to vary is the HV Skill's and is called by name.
- **A plan is frozen before its run and carries predictions;** a results file names what it did not test; a change to the skill is a new numbered file, made only after a test forces it.
- **Never a Fable 5.1 reader under test; never a Fable 5.1 or Opus 5 subagent without the owner's explicit permission** (HV decision H4, which the owner set for all of this work).
- **The record split rule holds:** numbering is this project's own (P1 first); work here edits only this folder.

## Words used in this project
- **Plan, prediction, frozen.** A plan is the numbered file written before a run; its predictions are ticked in the results file; frozen means unedited after the first run goes out.
- **Fitting, held-out, reserve.** The sources a change was written from or checked on; the sources no marker has read, spent once a version is judged on them; the keyed corpora kept for answer-keyed tests.
- **First marker, second marker, third reading.** Whoever marked first; a marker that saw neither the labels nor the first marks; the reading that settles a disagreement, which no plan here has run yet.
